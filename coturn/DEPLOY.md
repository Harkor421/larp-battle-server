# Deploying Larp Battle on Hetzner (P2P + self-hosted coturn)

Target architecture (the ~$110–160/month one):

```
Players' browsers ──── video: direct P2P WebRTC (≈85% of calls, costs you $0)
        │ │                     │
        │ └── video via TURN relay when P2P impossible (≈15% of calls)
        │                       │
        ▼                       ▼
  App server (Node)        coturn (TURN/STUN)
  signaling + matchmaking  Hetzner EX44, unlimited 1 Gbit
  frames → GPT-4.1-mini    €44/mo
  (can be the same box)
```

Phase 1 (launch): run **everything on one Hetzner EX44** (€44/mo — 14 cores,
64 GB RAM, 1 Gbit unmetered). It carries the app plus TURN relay for thousands
of concurrent users. Phase 2 (growth): move the app to a small cloud VPS and
add a second EX44 for TURN redundancy.

---

## 1. Order the server

- Hetzner Robot → Dedicated → **EX44** (€44/mo, no setup fee promo varies).
  Choose Ubuntu 24.04 LTS.
- DNS: create `battle.YOURDOMAIN.com` (the app) and `turn.YOURDOMAIN.com`
  (coturn) → both pointing at the server IP.
  - `battle.` can be proxied through Cloudflare (orange cloud) — free TLS, DDoS
    protection, and the free `CF-IPCountry` header the app uses for flags.
  - `turn.` must be **DNS-only (grey cloud)** — TURN traffic cannot go through
    Cloudflare's proxy.

## 2. Base setup

```bash
ssh root@YOUR.SERVER.IP
apt update && apt upgrade -y
apt install -y ufw fail2ban git curl

# Firewall
ufw allow OpenSSH
ufw allow 80/tcp 443/tcp          # app (or Cloudflare origin)
ufw allow 3478/udp 3478/tcp       # TURN
ufw allow 5349/tcp                # TURNS (TLS)
ufw allow 49152:65535/udp         # TURN relay range
ufw enable
```

## 3. coturn

```bash
apt install -y coturn
# Enable the daemon
sed -i 's/#TURNSERVER_ENABLED=1/TURNSERVER_ENABLED=1/' /etc/default/coturn

# TLS cert for TURNS (stop anything on :80 first)
apt install -y certbot
certbot certonly --standalone -d turn.YOURDOMAIN.com
# Let coturn read the certs
usermod -aG ssl-cert turnserver 2>/dev/null || true

# Install the config from this repo
cp coturn/turnserver.conf /etc/turnserver.conf
# EDIT IT: realm/server-name, listening-ip/external-ip, cert paths, and
# static-auth-secret (generate with: openssl rand -hex 32)

systemctl enable --now coturn
systemctl status coturn
```

Test it: https://webrtc.github.io/samples/src/content/peerconnection/trickle-ice/
— add `turn:turn.YOURDOMAIN.com:3478` with a credential generated by the app's
`/api/ice` endpoint (or temporarily with `lt-cred-mech` test creds). You should
see `relay` candidates.

## 4. The app

```bash
# Node 20+
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs

adduser --system --group larp
mkdir -p /opt/larp-battle && chown larp:larp /opt/larp-battle
# Copy the project there (git clone or rsync), then:
cd /opt/larp-battle
sudo -u larp npm install --omit=dev

cp .env.example .env
# EDIT .env:
#   OPENAI_API_KEY=sk-...
#   TURN_HOST=turn.YOURDOMAIN.com
#   TURN_SECRET=<same value as static-auth-secret in /etc/turnserver.conf>
chmod 600 .env && chown larp:larp .env
```

systemd unit — `/etc/systemd/system/larp-battle.service`:

```ini
[Unit]
Description=Larp Battle
After=network.target

[Service]
User=larp
WorkingDirectory=/opt/larp-battle
ExecStart=/usr/bin/node server/index.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now larp-battle
```

## 5. TLS / reverse proxy for the app

**Option A — Cloudflare in front (recommended, free):** orange-cloud
`battle.YOURDOMAIN.com`, set SSL mode "Full (strict)", install a Cloudflare
origin certificate in a local nginx/caddy, and you automatically get the
`CF-IPCountry` header (enable it: Cloudflare dashboard → Network →
IP Geolocation). WebSockets pass through Cloudflare fine.

**Option B — Caddy direct:**

```bash
apt install -y caddy
cat >/etc/caddy/Caddyfile <<'EOF'
battle.YOURDOMAIN.com {
    reverse_proxy localhost:3000
}
EOF
systemctl restart caddy
```

Without Cloudflare, country lookup falls back to the bundled GeoLite2 data in
`geoip-lite` — still free, slightly staler.

> getUserMedia (camera) only works on HTTPS origins (or localhost), so TLS is
> mandatory before anyone can actually battle.

## 6. Sanity checks

```bash
curl -s https://battle.YOURDOMAIN.com/healthz
# {"ok":true,"battles":0,"queued":0,...}
```

Open the site in two browsers (one in a private window), accept the gate in
both, hit "Find a battle" in both — you should get matched, connect, battle for
2 minutes, and receive an itemized verdict.

## 7. Scaling later

- **More TURN capacity:** add EX44s, put all of them in the `iceServers` list
  (`TURN_HOST` can become a comma list with a small code tweak) — each box adds
  ~1 Gbit of relay headroom, enough for ~600+ additional *relayed* calls.
- **More signaling capacity:** the Node process is a single core doing tiny
  JSON messages; one box handles tens of thousands of connections. Past that,
  move matchmaking state to Redis (queue as a sorted set + pub/sub) so multiple
  app instances can share it.
- **Judge spend:** the only cost that scales with battles, not with users.
  ~$0.02/battle at defaults (deduped frames); set `JUDGE_ALL_FRAMES=true` to
  send every 1s frame (~$0.10–0.13/battle).
